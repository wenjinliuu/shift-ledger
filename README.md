# 工时簿

面向综合工时制的个人排班、工时记录与加班费预测工具。采用手机优先设计，可作为 PWA 添加到桌面使用。

## 功能

- 综合工时：月总工时减去当月基本工时，得到加班工时
- 普通月薪：支持工作日、周末和法定节假日倍率
- 内置四白两休四夜两休、一白一夜休二、两白两休两夜两休和四班三倒模板
- 自定义“白 / 夜 / 休”或“早 / 中 / 晚 / 休”循环，从指定生效日向后更新并保留历史排班
- 区间批量修改：依次选择开始日和结束日，统一修改整段日期
- 日历逐日调整班次、工时、请假、节假日和备注
- 自动识别每年 13 个法定节假日，并按 3 倍规则独立计算
- 预测与实际工时、收入、加班费分别统计
- 蓝紫分段年度柱状图、基本工时线和月度预测明细
- 工资金额一键隐私隐藏
- JSON 数据备份导出与导入恢复
- 手机端液态玻璃界面和桌面模式

## 数据说明

当前版本的数据保存在浏览器本机，不会上传到服务器。更换设备或清除浏览器数据前，请先在设置页导出 JSON 备份。

公开版本不包含任何个人工资和每日记录：底薪默认为 0，排班模板只包含已公开确认的通用规律。首次使用时请在设置页和循环排班中填写自己的数据。

法定节假日判定以《全国年节及纪念日放假办法》规定的 13 个法定日为准，不把调休形成的普通休息日算作 3 倍日。农历日期和清明节气由 `lunar-typescript` 在本机计算。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目使用 Next.js 静态导出，Netlify 发布目录为 `out`。`main` 分支更新后，Netlify 会自动重新构建和发布。

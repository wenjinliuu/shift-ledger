# 工时簿

面向综合工时制的个人排班与工时累计工具。采用手机优先设计，可作为 PWA 添加到桌面使用。

## 功能

- 综合工时：月总工时减去当月预计基本工时，得到加班工时
- 日历、统计、设置三栏结构，月度排班与工时展望集中在日历页
- 内置四白两休四夜两休、一白一夜休二、两白两休两夜两休和四班三倒模板
- 自定义“白 / 夜 / 休”或“早 / 中 / 晚 / 休”循环，从指定生效日向后更新并保留历史排班
- 两班倒与三班倒设置会和循环排班自动联动
- 区间批量修改：依次选择开始日和结束日，统一修改整段日期
- 日历逐日调整班次、工时、请假、节假日和备注
- 自动识别每年 13 个法定节假日
- 按“周一至周五 × 日标准工时 − 落在工作日的法定节假日”自动推算 2025—2050 年每月基本工时
- 预计基本工时支持逐月手动修正，以适配每年另行发布的调休和补班安排
- 单页年度工时仪表盘，使用蓝紫分段柱状图、蓝紫阶段进度和绿色实时完成同心环展示全年工时状态
- JSON 数据备份导出与导入恢复
- 手机端液态玻璃界面和桌面模式

## 数据说明

当前版本的数据保存在浏览器本机，不会上传到服务器。更换设备或清除浏览器数据前，请先在设置页导出 JSON 备份。

首次使用保持空日历，不会自动生成任何班次。可从循环排班模板开始，也可以逐日手动记录。

法定节假日判定以《全国年节及纪念日放假办法》规定的 13 个法定日为准。农历日期和清明节气由 `lunar-typescript` 在本机计算。未来年度的调休与补班并非固定规则，因此自动值会明确标记为推算值，并保留手动修正入口。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目使用 Next.js 静态导出，Netlify 发布目录为 `out`。`main` 分支更新后，Netlify 会自动重新构建和发布。
